边界：只修改 GEO 演示夹具、必要的前端接线和验证文件。模拟内容明确标识，不进入正式数据库、报告或证据链。不据样例宣布 Foundation/Product API 连通；不运行真实模型，不部署、提交或推送。本授权不是整体重构方案批准。
